วิธีที่ 3: เปิดสิทธิ์ file:// ใน MetaMask

เปิด Chrome ไปที่ chrome://extensions → หา MetaMask → คลิก Details (รายละเอียด) → เลื่อนลงมาเปิดสวิตช์ "Allow access to file URLs" (อนุญาตให้เข้าถึง URL ของไฟล์) แล้วรีเฟรชหน้านี้ครับ
